# Drizzle ORM Migrations

This folder contains **Drizzle-generated SQL migrations** which are now the **source of truth** for database schema changes.

## Workflow

### 1. Update Schema Definition
Edit the Drizzle schema in [`src/db/schema.ts`](../src/db/schema.ts)

```typescript
export const workEntries = sqliteTable('work_entries', {
  // Add/modify columns here
  id: integer('id').primaryKey({ autoIncrement: true }),
  // ...
})
```

### 2. Generate Migration
Run Drizzle Kit to automatically generate a migration from schema changes:

```bash
npx drizzle-kit generate
```

This creates a new timestamped SQL file in `drizzle/` folder.

### 3. Apply Migration
Migrations are automatically applied at app startup via [`src/db/migrate.ts`](../src/db/migrate.ts).

For manual migration in tests:
```bash
npm run test:drizzle
```

## Migration Files

- **Drizzle migrations**: `drizzle/NNNN_name.sql` - Auto-generated by Drizzle Kit (primary source of truth)
- **Custom migrations**: `migrations/*.sql` - Manual migrations when needed (e.g., data transformations, UUID migration)

## Important Notes

- ✅ **DO**: Edit `src/db/schema.ts` for schema changes
- ✅ **DO**: Run `drizzle-kit generate` after schema changes
- ❌ **DON'T**: Edit generated migration files manually (unless necessary)
- ❌ **DON'T**: Use `work-entries.schema.sql` anymore (deprecated)
